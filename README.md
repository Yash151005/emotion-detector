# Emotion Detector Web Application

This project is an AI-powered emotion detection web application built using the Watson NLP library and Flask.

## Features
- Detects emotions from text input
- Returns anger, disgust, fear, joy, sadness scores
- Displays dominant emotion
- Web interface using Flask
- Unit testing included
- Static code analysis using pylint

## Technologies
- Python
- Flask
- Watson NLP API
- Requests
- Unittest
